# Actual icon morphs and expressive underlines

Checked 2026-10-03. Scope: ready-made individual parts; no prescribed aesthetic or universal duration. Primary source links below record the inspected code and licenses. Raw research receipts remain in the local task record; this report does not claim product integration.

## Exact sun/moon morph choices

| Ready-made part | Actual mechanism verified | Reuse and fit |
| --- | --- | --- |
| [Toggles.dev Classic demo](https://toggles.dev/toggles/classic) | One circle scales from sun disk to moon body. Its SVG clipping path changes `d` while rays shrink/disappear. The cutout progressively carves the crescent; it is not two complete icons crossfading. | MIT. React/Svelte/Vue packages or source copying. Recognizable radial sun and solid crescent. [Exact React source](https://github.com/alfiejones/theme-toggles/blob/main/packages/react/src/Classic.tsx). |
| [Toggles.dev Expand demo](https://toggles.dev/toggles/expand) | Shared circle expands to 1.6 scale, surrounding dot rays contract to 0.75, changing clipping-path geometry cuts out the moon. Staged easing includes an overshooting curve. | MIT. Same integrations; visually different dotted sun and expanding/cutout treatment. [Exact React source](https://github.com/alfiejones/theme-toggles/blob/main/packages/react/src/Expand.tsx). |

**Live verification of Classic:** opened the official demo in the in-app browser, clicked the demo control, and inspected the rendered SVG/computed styles. Before: `d=M0 0h25a1 1 0 0010 10v14H0Z`. A mid-transition read returned computed `path("M 0 1.6519 H 15.0886 A 1 1 0 0 0 25.0886 11.6519 V 25.6519 H 0 Z")`. Endpoint: `path("M 0 2 H 13 A 1 1 0 0 0 23 12 V 26 H 0 Z")`, circle scale `1.7`, rays opacity `0`; screenshot visibly showed the crescent. This proves live interpolated geometry on this browser. It does not establish timing quality across devices, rapid-toggle behavior, or every browser. Expand is source-verified, not playback-verified.

Current [React package manifest](https://github.com/alfiejones/theme-toggles/blob/main/packages/react/package.json) is MIT, version 5.0.5, with React `^19.0.0` peer dependency and no animation runtime dependency. Import the shipped per-toggle CSS with the npm package; source classes use generated utility CSS, so copying TSX alone into a non-Tailwind app is insufficient. [Usage](https://github.com/alfiejones/theme-toggles/tree/main/packages/react) provides the CSS import. The sources have a `duration` prop (Classic default 400 ms, Expand 500 ms); these are upstream defaults, not recommendations.

Source limitations: both gate animation with `motion-safe`, preserve the immediate dark/light geometry without motion, use `currentColor`, native buttons, labels, hidden decorative SVG, and unique React `useId` clipping IDs. They include a translated clipping-path fallback when CSS `d:path` is unsupported. Contrast remains the host's responsibility. `aria-pressed` is supplied from `toggled` or caller props; the live demo instead applied a `dark` class and had no `aria-pressed`, so do not infer accessible state announcements from the demo. Source contains no click lock or explicit animation queue; rapid reversal remains a runtime acceptance check. Theme persistence/provider behavior belongs to the host.

## Expressive underline choices

| Part / official demo | What moves | Integration and limits |
| --- | --- | --- |
| [Codrops LineHoverStyles: Carme](https://tympanus.net/Development/LineHoverStyles/) (Writings) | A wavy/scribbled SVG path draws via normalized `pathLength=1` and stroke-dashoffset. | MIT; CSS + inline SVG, no animation library. Deliberately irregular handwritten line. |
| Same gallery: Herse (Sign up) | A curved SVG arc draws beneath/around the text using dashoffset. | MIT; different silhouette and placement from a straight growing underline. |
| Same gallery: Iocaste (Learn more) | A long SVG curve translates across a clipped link, giving a traveling hump/wave. | MIT; CSS + SVG, no path interpolation. More spatial motion than a draw-on stroke. |
| Same gallery: Eirene (Contact) | A thick rounded bar compresses into a thin line while text moves down, with a spring-like cubic-bezier. | MIT; CSS-only. A physical squeeze/settle treatment. |
| [Rough Notation underline demo](https://roughnotation.com/) | RoughJS-generated paths progressively draw; default two passes go left-to-right then back. | MIT; framework-neutral JS, optional wrappers. `multiline`, color, stroke width, padding, iterations, and animation duration configurable. |

[Codrops exact CSS](https://github.com/codrops/LineHoverStyles/blob/main/css/base.css), [inline SVG/markup](https://github.com/codrops/LineHoverStyles/blob/main/index.html), [MIT license declaration](https://github.com/codrops/LineHoverStyles). These are extracted snippets, not packaged React components. The demo includes Adobe Typekit fonts, which are separate assets; choose host fonts instead of treating the font kit as MIT. Global demo CSS should be scoped before reuse. SVG stroke is hardcoded black while pseudo-elements use currentColor; update SVG stroke for dark themes. Keyboard focus outline exists, but hover animation selectors do not also target focus-visible. No reduced-motion handling appears in the inspected CSS. Single-line nowrap examples need adaptation for wrapped prose. Transitions can reverse, but keyframe-based variants restart; interruption was not played or tested.

[Rough Notation exact renderer](https://github.com/rough-stuff/rough-notation/blob/master/src/render.ts), [lifecycle source](https://github.com/rough-stuff/rough-notation/blob/master/src/rough-notation.ts), [manifest](https://github.com/rough-stuff/rough-notation/blob/master/package.json), [API](https://github.com/rough-stuff/rough-notation/blob/master/README.md). RoughJS is a build dependency bundled into the distributed files; the manifest declares no runtime dependencies. SVG uses currentColor by default. No automatic reduced-motion preference check was found; caller can set `animate:false`. `hide()` immediately removes paths rather than animating backward; `show()` while showing refreshes without replay, and hide/show replays. It inserts a sibling SVG and measures DOM rectangles, so table layout, fonts loading, and unmount cleanup require attention. README and renderer disagree on default stroke width (1 vs 2), so set it explicitly. These are source-verified; underline demos were not played.

## Excluded false positives

[Joly UI Animated Theme Toggle](https://www.jolyui.dev/docs/components/inputs/animated-theme-toggle) calls itself a sun-to-moon SVG morph, but the published excerpt describes separate moon/sun scales and path-length drawing. This is an animated substitution unless a different source proves shared geometry. Scene toggles with clouds/mountains and page-theme wipes do not satisfy the icon-morph requirement. The choices above preserve that distinction.
