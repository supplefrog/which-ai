# Iteration 5 — RE:CALL / the recall room

Provisional concept: a vermilion-and-ice-mint invitation to put old thoughts back into motion. Large sans typography and a three-stage thought track lead into a synthesis console. The lower-page invitation carries the same rewind/reuse idea. This is an isolated taste preview, not a production application.

## Necessary tasks and expected feedback

- Start the demo from either primary action: scroll to the console and focus its first intention.
- Change intention: update the question and selected sample fragments, clear the previous brief.
- Include or exclude fragments: checkbox-style pressed state and selected count agree.
- Bring fragments together: assemble the actual selected note bodies into an editable brief, followed by the intention's clearly disclosed preset next step. No remote AI is implied.
- Capture a personal thought: open an inline labeled textarea, preserve empty input with a recovery error, add a nonempty note to the selected thread. Cancel returns to the add action.
- Edit and copy the brief: clipboard success is announced; denied/unavailable clipboard leaves the editable text available for manual copy.
- Empty selection: building reports a recoverable error. Reset restores sample notes.
- Phone transformation: vertically stack the thought track and the fragments/output panes. Keep native controls and at least 44px targets.

## Sources and assets

No remote component code, imagery, fonts, or generated assets. Native React/HTML state and controls; installed lucide-react icons (ISC license). Arial and Courier New are system font stacks. The provided dependency manifest was inspected. This preview makes no customer, pricing, or performance claims. Notes are sample content and session-local only.
