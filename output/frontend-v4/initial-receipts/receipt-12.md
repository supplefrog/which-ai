## State and recovery paths

- Morrow: Select one of the hero thoughts, select a collection entry, capture a thought with a chosen collection, preserve invalid input, announce empty-submit error, announce successful capture, reset added entries. Capture actions scroll to and focus the local writing field. Journal selections crossfade the entire reading content with entry and exit, while reduced motion makes the state change instant. New entries are held only in component memory until reload.
- Lattice: Select map nodes, select/search collection entries, follow a connected thought, clear an empty search, add a new node connected to the focused thought, and reset the example. Title and body are required; invalid input is preserved and focus moves to the missing field. Success announces the created relationship. The six-node preview allows two new thoughts, then exposes a disabled full-map state and a reset action. Changing the selected note changes the map indication, collection selection, reading content and capture connection target. Whole reading content has short directional fade transitions; SVG connection/point selection changes continuously. Reduced motion removes nonessential transitions. No pretend asynchronous/loading behavior is used because all updates are synchronous and local.
- Native links/buttons/forms; visible input labels; scoped focus indication; skip links; noncolor selected text; error/status announcements. No modal, hidden account flow, paid action, or remote save claim.
- Responsive transformations: Morrow moves from editorial two-column to stacked hero/book; at the narrowest size its collection precedes the reader vertically.
