# Acceptance cases frozen before browser input

Shared coverage: inspect all five complete pages at desktop and narrow widths; verify headings, readable content, accessible primary actions, document overflow and console errors. Exercise the local demonstration rather than counting event handlers. Check meaningful selection feedback, repeated/reversed input, keyboard activation/focus and reduced motion. Narrow testing is browser emulation, not a physical phone test.

1. Margin: primary action reaches/focuses capture; empty save preserves recovery; save adds and opens the actual authored thought; title/body search and no-match state work; tag filtering and move actions maintain the note's own visible identity. The reader may retain an already-open note when the result filter changes. Hero fragments open their corresponding note without initiating a different task.
2. Thread: primary action reaches capture; trail selection changes source and question coherently; connect/unlink updates both explanation and indicator, reversibly; capture preserves the selected trail; saved thought search and no-match recovery work; reset restores demo state.
3. Commonplace: primary action opens/focuses editor; empty submission reports the missing content; collection selection is native and visibly themed; save opens the actual new note in the chosen collection; cancel returns focus and retains draft; search/no-match reset and collection/note selection work.
4. Fieldwork: projects, selected node, highlighted connector and inspector agree; line endpoints meet the intended centers at desktop/intermediate geometry. On phone the graph transforms to a usable ordered note list. Add/save/cancel support validation, retained draft and visible focus return; additions stay with their project and appear in the connected-thought count/list.
5. RE:CALL: intention, selected fragments and count agree; build assembles the actual chosen bodies and disclosed preset next step; empty selection reports recovery; brief is editable and copy succeeds or leaves usable manual-copy recovery; own-thought add/cancel/validation and reset work.

Collection forms must retain readable long authored text without document overflow. Check complete lower content and actions, not only the hero. Inspect transitions at normal speed where present; rapid reversals must not leave mismatched selection/content. Instant content replacement is an authored choice in this draft and remains visible for taste judgment; no universal animation requirement is invented for this run.
